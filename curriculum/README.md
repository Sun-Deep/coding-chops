# Curriculum

The curriculum is organized by learning track. Each official lesson moves through four gates:

1. Research
2. Understanding
3. Script and storyboard
4. Render and editorial review

A beautiful render does not bypass the understanding gate.

## Tracks

- [System Design](system-design/README.md)
- [Data Structures and Algorithms](dsa/README.md)
- [Problem Solving](problem-solving/README.md)

Use the files in [`templates/`](templates/) when starting a lesson or retention experiment.
