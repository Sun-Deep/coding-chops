# Short-form hypotheses

These are test hypotheses, not approved titles or scripts.

## Short 1: Request path

- Question: What happens after you tap a button?
- Complete answer: Trace client, application, database, and response.
- Long-form bridge: The master lesson explains which work happens at each component.

## Short 2: User count misconception

- Question: Can one server handle 10,000 users?
- Complete answer: User count alone is insufficient. Request rate, concurrency, and work per request determine pressure.
- Long-form bridge: The master lesson introduces where those resources are consumed.

## Short 3: CPU compared with I/O

- Question: Why can a server be slow when its CPU is not full?
- Complete answer: It may be waiting on disk, a database, or the network.
- Long-form bridge: The master lesson traces the complete request path.
