# Lesson checklist

## Learning objective

After this lesson, the viewer can:

- [ ] State the concept in plain language
- [ ] Draw the data flow from memory
- [ ] Explain the problem the concept solves
- [ ] Identify when the concept should not be used
- [ ] Compare at least one alternative
- [ ] Predict a failure mode
- [ ] Apply the concept to a new scenario

## Research gate

- [ ] Important claims have authoritative sources
- [ ] Terminology is precise
- [ ] Simplifications are labeled
- [ ] Common misconceptions are addressed

## Production gate

- [ ] Script follows passed understanding checks
- [ ] Storyboard adds explanatory value
- [ ] Horizontal and vertical lessons are independently scripted
- [ ] Captions stay within the format safe area
- [ ] Representative frames were reviewed
- [ ] Technical and editorial reviews passed
