# Lesson checklist

## Learning objective

After this lesson, the viewer can:

- [ ] State the concept in plain language
- [ ] Draw the data flow from memory
- [ ] Explain the problem the concept solves
- [ ] Identify when the concept should not be used
- [ ] Compare at least one alternative
- [ ] Predict a failure mode
- [ ] Apply the concept to a new scenario

## Research gate

- [ ] Important claims have authoritative sources
- [ ] Terminology is precise
- [ ] Simplifications are labeled
- [ ] Common misconceptions are addressed

## Production gate

- [ ] Script follows passed understanding checks
- [ ] Narration is locked before final animation
- [ ] Every narration file has been measured
- [ ] Timestamped caption JSON matches the locked narration
- [ ] Storyboard adds explanatory value
- [ ] Every shot teaches one clear idea with one hero object
- [ ] Hero-object continuity is preserved between shots where possible
- [ ] Horizontal and vertical lessons are independently scripted
- [ ] Captions stay within the format safe area
- [ ] Caption start, midpoint, and end frames were inspected
- [ ] Captions do not overlap or resemble editorial notes
- [ ] Representative frames were reviewed
- [ ] Every visual element has an understandable purpose
- [ ] Technical simplifications and illustrative numbers are labeled
- [ ] Narration is the clearest audio layer
- [ ] Audio sources and licenses are documented
- [ ] Complete horizontal and vertical renders were produced
- [ ] Both complete renders were watched from beginning to end
- [ ] Thumbnail and platform covers were reviewed at final size
- [ ] Technical and editorial reviews passed
