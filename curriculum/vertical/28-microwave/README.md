# Vertical 28: should quick meals skip the line

Status: built, not posted

## What it claims

At one office microwave with eight people in line, letting whoever has the
shortest heating time go next cuts the average wait from 7:00 to 4:06, 42%
less, with the same microwave doing the same 14 minutes of work. The cost is
the person with the longest job: first in line, they wait 0:00 under first
come, first served and 10:35 when the quick ones go first.

Operating systems call the rule shortest job first. With everyone already
waiting it gives the lowest average wait of any order (Smith 1956).

## Why this topic

It is the clean test of the coding beat. Gridlock named its coding idea
and missed, but it also changed the picture and the pacing, so one reel
could not say which cost it. This one keeps what the everyday escapes had:
a place everyone has stood in, a race visible from the first frame (the live
average wait climbs faster on top), and a rule people argue about. Only the
last line and the bottom label name the coding idea.

## Scope

A line that has already formed, everyone's heating time known and honest,
and nobody interrupted once their food is in. The script also checks people
arriving over time, where shortest first still cuts the average by 37 to
42%, and how the longest single wait grows, which is the starvation an
operating system has to guard against.
