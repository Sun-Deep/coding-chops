# Sources

- Smith, W. E. (1956). Various optimizers for single-stage production. Naval
  Research Logistics Quarterly 3(1-2), 59-66. Ordering jobs shortest first
  minimises the total, and so the average, completion time on one machine.
- Silberschatz, A., Galvin, P. B. and Gagne, G. Operating System Concepts,
  CPU scheduling chapter: shortest-job-first scheduling is optimal for
  average waiting time, needs the length of the next burst, and can starve
  long processes; ageing is the usual fix.
- The run: `scripts/measure-microwave.mjs`, which imports
  `src/vertical/28-microwave/simulation.ts`, the same module the reel draws.
