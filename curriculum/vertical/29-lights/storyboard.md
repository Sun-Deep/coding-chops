# Storyboard

One shot: the same tree twice, side by side, with the same dark string and
the same bad bulb, number 70.

## The clock

Three times real time for the first four and a half seconds, so every check
on the right can be followed as the glowing stretch halves: 50, 75, 63, 69,
72, 71, 70. The clock then hurries through the bulb swap, the right tree
lights at frame 167, and it settles at thirteen times real time so the left,
still going bulb by bulb, lights at frame 386.

## Drawing

The string zig-zags up the tree in seven sagging rows. The stretch that could
still hold the bad bulb glows along the wire, and the readout above says how
many bulbs that is: 100, 50, 25, 13, 7, 4, 2, 1 on the right, 100, 99, 98 on
the left. The first build marked those bulbs with small rings; the creator
asked whether it had the gridlock reel's problem, and at phone size the rings
were a speckle, so the halving now shows as a band and a number that can be
read at feed size.
The hand comes from the lower right; the tester's light blinks while it
senses power and stays dark when it does not. Lit bulbs glow warm white and
the room takes a warm light from the tree.

## Colour

Orange is one bulb, the bad one, once found. Warm white is light. The tree is
decorated the way a real one is, at the creator's request after the first
cut's near-black tree: green branches, baubles in deep red, gold, silver and
blue, a gold star, wrapped presents and a red skirt. Those colours are
scenery and kept off orange, so orange still means only the bad bulb. This
is a choice for this reel, not a change to the channel's palette.

## Cue map

```text
check finds power   beep
check finds none    low tick
tree lights         chime
payoff              settle
```

## Checks run

Duration 14.06 s. Peak -5.1 dBFS. Three gaps of 0.36 to 0.39 s between
checks. No frame without change: the tester blinks through every hold, and
the swap moves the hand. Quarter-scale glance at frame 15 readable.
