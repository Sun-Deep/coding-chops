# Vertical 37: why buses arrive together

Status: posted 2026-10-15

One delayed bus collects more passengers. Boarding takes longer. The bus
behind encounters smaller queues and catches up. The final line names the
reinforcing loop as positive feedback.

This cut follows the orange bus on one road. The camera moves with it. The
following bus reaches its passenger stop at 1.8 seconds, picks up passengers,
then closes the gap and stops behind the first bus while boarding continues. Vehicles are enlarged and road
distances compressed so boarding and the changing gap remain readable on a
phone. The road is a schematic, not a distance scale.

The model uses identical driving speeds, seeded passenger arrivals and a fixed
boarding time per passenger. Its results describe these assumptions, not a
measured bus service. The opening follows an imposed delay. It does not claim
that passenger boarding is the only cause of bunching.

The following bus is blocked for 22.75 modelled seconds at the third stop.
The cut holds that wait for about 2.8 seconds and reports about 23 seconds
after the blockage ends. This comes from the same run as the animation.
