# Sources

- Franco Bocci, "Whether or not to run in the rain", European Journal of
  Physics 33 (2012): for vertical rain, run as fast as you can; with the
  wind behind you, the best speed can be the wind's.
- Thomas Peterson and Trevor Wallis (US National Climatic Data Center,
  1997), weighing identical clothes after walking and running 100 m in
  real rain: the runner got about 40% less wet.
- MythBusters: the 2003 test (artificial rain) found running wetter; the
  revisit in real rain found running drier.
- Raindrop fall speeds: Gunn and Kinzer (1949), via the polynomial fit of
  Atlas, Srivastava and Sekhon (1973), as used in the disdrodb package.
- The run: `scripts/measure-rain-run.mjs`, which imports
  `src/vertical/40-rain-run/simulation.ts`, the same module the reel draws.
