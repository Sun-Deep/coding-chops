# Storyboard

One shot. Frame 0 is close on the front row: HEAD, orange, at the left,
the rest of the field running back into the dark. The camera pulls back to
show all 1,000 as git starts. Each check lifts the commit under test, the
card turns bright chalk (ok) or orange (FAIL), and the half git rules out
goes over like dominoes in a wave from that card. After each answer the
camera moves in on what is still standing, so every halving is the same
step closer. Ten checks in, two cards stand: the last good one in chalk
and the first bad one in orange, which rises. The terminal shows the line
it changed.

## Built to read without the narration

A field of lights that loses half of itself, ten times, until one orange
card is left; the CHECKS chip counting to 10 while LEFT TO TEST falls
499, 249, 124 ... 0.
