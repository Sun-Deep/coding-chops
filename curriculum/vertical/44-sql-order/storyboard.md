# Storyboard

One shot. Frame 0 is close on the front of a printed table of 1,000
orders, dim. FROM: a band of light sweeps it from the back as Postgres
reads it, and the camera pulls back to the whole table. WHERE: the scan
reaches each unpaid row and it sinks. GROUP BY: the paid rows lift and
fly onto one stack per customer. HAVING: the stacks of fewer than 8 go
dark. SELECT: each stack left folds into one row that stands on end, as
tall as the customer's total, and turns orange. ORDER BY: they slide into
a line, tallest first. LIMIT: all but five fall. The camera ends on the
five, named, beside psql's answer to the alias in WHERE and in ORDER BY.

## Built to read without the narration

The query at the top gains a number on each line as that step runs, so
by the end it reads 5, 1, 2, 3, 4, 6, 7 down the side, with SELECT's 5 in
orange.
