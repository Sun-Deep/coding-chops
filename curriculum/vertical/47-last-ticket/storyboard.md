# Storyboard

Two takes of the same moment, at eye level in a cinema, cut hard between
them. Take 1: both phones light up in the same frame, both read 1 left,
both celebrate, both walk to F12; the first sits, the second arrives with
a ticket for a seat that is taken, and seats_left goes to -1. Take 2: the
same taps. An orange padlock drops onto F12 as the first buyer's read
locks the row; the second buyer's bubble says waiting. The lock lifts
when the first commits, the second reads 0 left and is told sold out, and
the first walks to the seat and sits.

## Built to read without the narration

Two people, one seat: twice they both end up there, once only one does,
and the only thing that changed is an orange lock.
