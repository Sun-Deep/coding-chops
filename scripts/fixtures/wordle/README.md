# Historical Wordle lists

Downloaded for VR54 from 3Blue1Brown's `videos` repository at revision
`9add2c2eebcbe40377d8dd08169a42d556dd7ebc`.

- `answers.txt` is the byte-for-byte `possible_words.txt` file, 2,309 words.
- `guesses.txt` is the byte-for-byte `allowed_words.txt` file, 12,972 words.

Source directory:
https://github.com/3b1b/videos/tree/9add2c2eebcbe40377d8dd08169a42d556dd7ebc/_2022/wordle/data

These are historical Wordle vocabulary inputs, not today's NYT answer pool.
The upstream revision has no root license file. The lists retain their source
attribution; this project does not claim authorship of the lists or relicense
them as its own code. No upstream animation, text, or art is copied into VR54.

The measurement run records the exact SHA-256 hash of each input. The scorer
needs no network access once these files are present.
